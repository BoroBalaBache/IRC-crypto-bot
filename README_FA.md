# بات آزمایشی خرید رمزارز ایران اکسچنج

این پروژه یک نمونه‌ی آزمایشی از بات تلگرام برای شبیه‌سازی فرایند خرید رمزارز است. 
کاربر شماره تماس خود را ارسال می‌کند، رمزارز و شبکه‌ی انتقال را انتخاب می‌کند،
 مقدار خرید و آدرس کیف پول را وارد می‌کند و در پایان یک پیش‌فاکتور موقت دریافت می‌کند.

> **توجه:** این نسخه برای آزمایش و بررسی فنی ساخته شده است. 
بات به سامانه‌های واقعی ایران اکسچنج یا درگاه پرداخت متصل نیست
 و سفارش واقعی ثبت یا پرداختی انجام نمی‌دهد.

## امکانات

- دریافت شماره تماس کاربر از طریق تلگرام
- نمایش منوی اصلی و شروع فرایند خرید
- پشتیبانی آزمایشی از رمزارزهای TRX، BTC، ETH و USDT
- بررسی حداقل و حداکثر مقدار خرید
- انتخاب شبکه‌ی انتقال متناسب با رمزارز
- دریافت آدرس کیف پول مقصد
- محاسبه‌ی کارمزد درصدی و ثابت
- صدور پیش‌فاکتور موقت با شمارش معکوس
- امکان بازگشت به مرحله‌ی قبل و لغو فرایند خرید
- امکان تأیید آزمایشی پیش‌فاکتور یا صدور مجدد آن پس از انقضا

## پیش‌نیازها

- Python نسخه‌ی 3.10 یا جدیدتر
- توکن بات تلگرام از 
	[@BotFather](https://t.me/BotFather)
- کتابخانه‌ی `aiogram` نسخه‌ی 3

### تنظیم توکن بات

برای امنیت، توکن نباید مستقیماً داخل کد نوشته شود.

کد باید توکن را از متغیر محیطی دریافت کند:

```python
TOKEN = os.getenv("TELEGRAM_BOT_TOKEN")
```

اجرای برنامه

از پوشه‌ی حاوی فایل اصلی اجرا کنید:

```
python main.py
```

## روش آزمایش بات

۱. دستور `/start` را برای بات ارسال کنید.
۲. شماره تماس خود را با دکمه‌ی اشتراک‌گذاری مخاطب ارسال کنید.
۳. گزینه‌ی «خرید رمزارز» را انتخاب کنید.
۴. رمزارز و مقدار خرید را مشخص کنید.
۵. شبکه‌ی انتقال را انتخاب کنید.
۶. آدرس کیف پول مقصد را وارد کنید.
۷. پیش‌فاکتور را بررسی و تأیید یا لغو کنید.
۸. در صورت انقضای پیش‌فاکتور، امکان درخواست پیش‌فاکتور جدید وجود دارد.


قیمت رمزارزها، محدودیت‌های خرید و شبکه‌های قابل انتخاب در بخش `CRYPTO_CONFIG` کد تعریف شده‌اند. 
این مقادیر آزمایشی هستند.

## محدودیت‌های فعلی

- **عدم اتصال به صرافی:** قیمت‌ها ثابت و آزمایشی هستند و API واقعی ایران اکسچنج فراخوانی نمی‌شود.
- **عدم پردازش پرداخت:** تأیید پیش‌فاکتور فقط وضعیت سفارش آزمایشی را تغییر می‌دهد.
- **ذخیره‌سازی موقت:** سفارش‌ها در حافظه نگهداری می‌شوند و با توقف یا راه‌اندازی مجدد برنامه از بین می‌روند.
- **عدم تأیید حساب کاربر:** دریافت شماره تماس به معنی بررسی یا تأیید حساب کاربر در ایران اکسچنج نیست.
- **اعتبارسنجی محدود آدرس کیف پول:** در نسخه‌ی فعلی فقط خالی نبودن آدرس بررسی می‌شود؛ معتبر بودن آدرس و سازگاری آن با شبکه تأیید نمی‌شود.
